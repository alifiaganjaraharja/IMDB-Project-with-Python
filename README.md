# IMDb: Movie Analysis

## Project Overview:
This repository is used as part of my portfolio to showcase not only analytical thinking, but also to showcase my technical skills in Python to analyze the IMDb Movie dataset.

## Dataset Description:
There are two CSV files in the 'data' folder of this repository. Note that those two CSV files are raw data, so if you wish to do analysis using this dataset, Data Cleaning is more likely to be needed. 

## Questions asked:
A few Python Scripts used in this project to answer these 5 main questions:

1. Ranking directors by their total number of movies.
2. Determining if there is a correlation between the total number of movies each director has made and their IMDB rating.
3. Ranking the most popular movie genres from the last five years (2019 - 2024)
4. Finding top-rated movies in general and filtering for movies with an IMDB rating of at least 8.00.
5. Which lead actors appear most frequently in top-rated films, and which Director–Actor pairs collaborate repeatedly?

For Analysis, Results, and Findings, head to the [IMDb] - Analysis with Python.ipynb Jupyter Notebook for further explanation.
